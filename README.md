# ESG Auditor

A simple web app to audit a company's ESG (Environmental, Social, Governance) compliance.

**Stack:** HTML, CSS, JavaScript (frontend) · PHP (backend) · SQLite (database)

## Features
1. Register / Login (PHP sessions, hashed passwords)
2. ESG audit form with live score preview
3. Auto-scoring engine with rating and recommendations
4. Dashboard with charts, audit history, and PDF report export

## Run locally
```
cd esg-auditor
php -S localhost:8000
```
Open http://localhost:8000 (the database is created automatically).
